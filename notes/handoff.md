# HANDOFF (rolling): the one file a new chat reads. Updated after every stage.

## How handoff works (design, 2026-11-17)
- A chat cannot open a new chat by itself and cannot read the usage meter. So the state lives in THIS file, kept current after every stage, and the new-chat prompt is always the same short text (below). If a chat dies or runs out, nothing is lost.
- The main chat updates "Current state" and "Queue" right after each agent reports (before launching the next one). The user's words "hand off" or a meter reading at or above the trigger below start a handoff.
- Triggers (the user reads the meter and tells the chat; the chat also asks for it before each agent): weekly 92% = stop launching agents and hand off; 5-hour window at 100% = fine, hand off only if the chat itself is very long (about 25 agent reports) or the user says so.
- At a handoff the chat: (1) makes sure this file is current, (2) says "handoff ready" and prints the new-chat prompt, (3) launches nothing more.

## New-chat prompt (always the same; paste it)
```
michadr. New chat. Read notes/handoff.md FIRST, then context.md lines 1-45 (standing rules). Do not read big files whole (Grep PROJECT-INDEX.md, use line ranges). Ask the user: is the last work committed, and the weekly meter. Then continue the Queue in order: one stage per agent run, ask before switching model or agent, stop and report after each, and update notes/handoff.md after each stage.
```

## Standing rules (short)
Never reach 100% weekly; stop launching agents at 92 to 95%. Fable only when the user says yes; Opus only for design and every call needs a yes. Sonnet 5.5 builds. The user commits by hand (git not on PATH). Tests run the packaged release: `npm run release -- --force` (only for a version never deployed; 0.35.8 is deployed, 0.35.9 is not) before `npm test`. Own Blender models need no credit; triangle caps are soft (flag draw calls, materials, shadows); every new cargo vehicle gets a bed entry in dist/cargo.js; collisions must feel like smooth push, no big gaps, hard stop only on crashes.
