## API for C6
`const panel=createTalkPanel(document.getElementById('talk'),{onPick(id){...},onClose(){...}})`
- `panel.show({name,chip,lines,replies})`: opens, clears the transcript, shows lines `{who,text}`, replies `{id,label,asked}`, focuses reply 1. who is a cast id, 'you' or 'system'.
- `panel.append({who,text})`: adds a bubble (keeps the last 6; empty text ignored). Use who 'you' for `echo`, 'system' for act text (wraps, italic, centred).
- `panel.setReplies(replies)`: replace the buttons after each chooseReply. An empty list shows one "Continue" button that closes (use it for ended:true).
- `panel.setChip(text)`, `panel.setClock(text)`: header chip and clock (design says the panel shows the clock).
- `panel.close()`: hides, calls onClose once, no "See you" (use before openStore/gigBoard hand-off; idempotent).
- `panel.leave()`: Escape/Q. Calls onPick('bye') if that reply is offered, otherwise close().
- `panel.focusNext() / focusPrev() / confirm()`: for a later gamepad. Wraps around.
- `panel.handleKey(event.key)`: returns true if used. Handles Esc/Q, ArrowUp/Down, Enter/E, digits 1-7. C6 calls it from its keydown handler while `panel.isOpen()` (and must preventDefault when true).
- `panel.moveChevron(x,y,visible)`: speaking chevron, pass smoothed screen px; one style write; hidden when not visible or closed.
- `panel.isOpen()`, `panel.speaker()` (last NPC who id).

C6 flow: onPick(id) -> chooseReply -> append(echo) -> append each line -> if ended: append act text, `setReplies([])` (Continue) or close() after about 1.5 s; else setReplies(result.replies). Also: skip #dialog anchoring while open, lock movement (modal) in show/close, and close with "See you" when the player walks more than 3 m away (call leave()).
